# Condition Classification Starter Dataset

This folder contains a small synthetic starter dataset for single-label condition classification.

Labels:
- `diabetes`
- `hypertension`
- `kidney_disease`
- `liver_disease`
- `anemia`
- `high_cholesterol`
- `thyroid_disorder`
- `gastritis`

Files:
- `train.csv`
- `val.csv`
- `test.csv`

Important:
- These examples are synthetic and are intended for prototyping the training pipeline, not for clinical validation.
- Real performance claims should only be made after training and testing on a real, expert-labeled dataset.
